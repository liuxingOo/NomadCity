# 基础版收尾清理计划

## Context

用户要求核查基础版（不含企业扩展）还有哪些没做完、需要完善的地方。

逐文件核查结论：**基础版规则与 UI 在功能层面已跑通**，之前记录的「特殊行动按钮未接线」已不成立（`specialActionButton` 在 `Game.unity:10562` 已赋值）。真正需要处理的是 **1 个幽灵字段 + 3 处死代码/过期注释**。

因此本计划 = 删掉那个凭空多出来的字段、修正被它带出来的过期文案、顺手清理两处死代码。
