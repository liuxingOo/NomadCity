## 1. 通用规则

1. **牌面结构**（自下而上）：**标题栏**（牌名 + 右上六边形奖励分数）／**中部图像**（背景叙事，无规则效果，虚线 `or` 右下角小字为叙事文）／**底部效果区**（关键词 + 入场效果图标与说明）。
2. **奖励分数**：右上六边形内数字，建设时立即结算（`RuleSpec` §6.4e 步 2）。**可以是负数**（如「简陋工程营」为 `-1`）。
3. **费用二选一**：牌面左侧竖排图标列 = **资源费用**；虚线 `or` 下方的金券图标数字 = **金券费用**。建设时二选一支付（§6.4e 步 1）。
4. **费用二选一的两组**：虚线 `or` 把费用分成**两组**，建设时**整组二选一**——上面那组是「资源费用」，下面那组是「金券费用」。资源费用组本身可以混入**金券**乃至**至纯源石**：「城邦工业区」= `源岩4 · 源石3 · 金券2`，「佣兵指挥部」= `源岩2 · 异铁2 · 金券4`，「物流枢纽」= `至纯源石1 · 金券2`（或 24 金券）。
5. **关键词**：见 §6.4e，牌面关键词有 `唯一`、`免费` 两种。`免费` 作为**牌关键词**表示建设时跳过支付。
   > **注**：41 张普通设施牌里**没有一张**把「免费」用作**牌关键词**——「高性能动力设施」牌面虽印有「免费」，
   > 但它紧邻城市移动图标，属于入场效果的一部分（只让城市移动免付 3 源石），建设照常付费，见 §4 与 §8 第 7 条。
6. **彩色设施**：颜色栏标 `彩色`，组合城市样式时可视为任意颜色（§6.5b）。
7. **颜色分布**：彩色 **11** / 蓝 **10** / 黄 **10** / 红 **10**，共 **41** 张普通设施牌，**没有绿色设施**。

## 7. 与代码的对应关系

- id 分段：普通设施 `CardIds.FacilityBase = 100`，共 41 个（100–140），**按素材拼版图从左到右、从上到下编号，跳过槽位 22／33／44（延伸枢纽）**；核心指挥塔 `200 + 颜色`；延伸枢纽 `300 + 序号`（沿用既有 `{红, 黄, 蓝}` 顺序）；企业办事处（企业扩展）`600 + 序号`（红 / 蓝 / 黄）。
- `FacilityCardDef` 字段落点：`Name` / `Color` / `Score` / `ResourceCost`（`RewardOp.Pay`）/ `VoucherCost` / `Keywords` / `EntryEffects` / `CostModifier`。
- **入场效果落码状态**（效果节点见 `RuleSpec.md` §11）：
  - **已落码**：「获得 N 资源」（源石精炼厂 / 异铁冶炼厂 / 固源岩提纯厂）、「放置影响力×N」（护航调度中心）、
    「`or` 二选一」（佣兵指挥部：替换 1 个影响力 **或** 放置 1 个影响力）、
    「条件计数」（城市化区域：每有一个与核心指挥塔十字相邻的设施获得 4 金券）。
  - **已落码（行动类节点，2026-10-17 补齐）**：进行一次建造（简陋工程营）、免费城市移动（高性能动力设施）、
    按单价售卖资源（贸易街区，源岩 3／源石 3／异铁 4／至纯源石 15）、结算他牌入场效果（附属能源设施，十字相邻非彩色设施）、
    传递起始标记（联邦理事会，本回合收尾阶段生效）、从余下延伸枢纽选 1 张并建设（物流枢纽）、
    执行 1 次探索（引擎节点已实现）。
  - **费用修正**（`FacilityCardDef.CostModifier`，在 `BuildFacilityCommand` 里折算，不走入场效果）：
    「城邦工业区」＝ 面板上每有 1 种非彩色设施，少付 1 源岩（`CountSource.NonColorFacilityKinds`，只减资源费用组，金券不受影响）。
  - **已落码（2026-10-18 补齐）**：**载具仓库（138–140）** —— 牌面 `or` 的分界无歧义，两个分支二选一（§11.4）：
    ①「拿走场上 1 个影响力（可以是别人的），然后移动 1 个自己的影响力」；②「执行 1 次探索」。
    （`RewardOp.Alternative` + `RemoveInfluence` + `RelocateInfluence` / `ExploreOnce`，见 `CardCatalog.cs`。）
  - **已落码（2026-10-18 补齐）**：**开采电铲（128–130）** —— 牌面「合计获得 5 个」（源岩／源石／异铁任意分配）
    由新增的 `RewardKind.GainSpread` 表达：`RewardOp.GainSpread(5, 源岩, 源石, 异铁)`；
    选择器新增 `IEffectChoices.ChooseResourceSpread`，UI 逐种问「给几个」（余量给最后一种，
    全给第一种时只弹一次窗）。引擎会把结果夹到「合计恰好 5 个」。
  - **已落码（2026-10-18 补齐）**：**高性能动力设施（124–125）牌面另印的那一行**「在经过的航道上放置 1 影响力」
    —— 城市移动只能移到**相邻**资源点（§6.4d 步 2，只经过一条航道），故落点就是那条航道上的空格；
    新增 `RewardKind.PlaceInfluenceOnCityMoveRoute`，所用航道记在 `GameState.LastCityMoveRouteId`。
    入场效果因此是 `FreeCityMove()` + `PlaceInfluenceOnCityMoveRoute()` 两条。
    **两条已确认裁决（见 §8 第 7、8 条）**：①建设照常按牌面两组费用二选一支付，「免费」只作用于入场效果里的城市移动
    （故该牌 `Keywords` 为 `None`、`IsFree` 为 false）；②航道那 1 个影响力是**额外**的，出发点那 1 个由城市移动本身完成，
    这次合计放 2 个影响力。
  - **玩家点选已接入 UI（2026-10-18）**：需要玩家选择的效果（放置落点、二选一分支、拿走／替换的目标、
    移动的起终点、建造的牌与空位、城市移动／探索的目标点、售卖数量、合计资源的分配）都由 `IEffectChoices` 回答。
    UI 的建设流程用 `EffectChoiceSession` 在**状态副本**上试跑入场效果，跑到需要选择处就停下、
    逐个弹窗（`ChoicePopup`）把该点的都问清楚，再把答案交回引擎正式执行；弹窗的选项按钮按需复制、
    超过一页自动分页。这样连锁节点（二选一里再挑落点、探索翻出的事件选项、结算他牌的入场效果……）
    的候选清单永远基于前面答案之后的真实状态。单元测试见 `Assets/Tests/EditMode/EffectChoiceSessionTests.cs`。
- **建设的分层交互（2026-10-18）**：点「建设」后按 `GameScreenController.BuildStep` 逐层推进，**每层都带返回键**：

  | 层 | `BuildStep` | 界面 | 返回键去向 |
  |---|---|---|---|
  | L0 | `PickCard` | 设施供应区 6 张牌弹窗 | `ActionPanel` 取消键 → 退出建设 |
  | L1 | `Pay` | 卡面放大（`CardPreviewPopup.ShowForBuild`）+ 三个按钮：**选项一（资源付费）／选项二（金券付费）／取消建设** | 取消建设 → 回 L0 |
  | L2 | `Slot` | 弹窗收起、进入选位模式：城市面板空位高亮（`CityPanelView` 半透明色块）、其他行动按钮全部禁用（`ActionPanel.SetLocked(true)`） | 取消键 → 回 L1 |
  | L3 | `Confirm` | 确认弹窗「在此处建造《X》？+N 分；获得…」［确定］／［取消］ | 取消 → 回 L2 |
  | L4 | `Effect` | 入场效果点选（`ChoicePopup` 或直接点地图） | 取消 → 回 L3 |

  - 付费按钮的可点状态由 `FacilityCardDef.CanPayWithResources(EffectiveResourceCost(...), ...)` 决定（含费用修正）；
    开发者模式（`ActionRules.IgnoresCosts`）下两个按钮都可用且不扣费。费用为 0 / 免费的牌（如城邦行政区无费用态）
    跳过 L1 直接进 L2。
  - **L4 与主要行动同源**：`ChoiceRequest.Pick`（`ChoicePick`）非空时，UI 不弹长列表，而是照主要行动的交互
    直接点地图——`ChoicePickKind.InfluenceSlot`（部署／调度／拿走／替换）用 `MapHit.IsSlot` 命中，
    `ChoicePickKind.Node`（城市移动／探索目标）用 `MapHit.Kind != MapHitKind.NodeBody` 命中；
    `ChoicePick.Slots` / `NodeIds` 的顺序即弹窗选项下标，点中第几个候选就是答案几。
  - **回退是纯 UI 行为**：所有选择都在**派发命令之前**完成，`EffectChoiceSession.Back()` 只丢掉最近一个答案
    再从头重跑（`Advance()` 每次都 `seed.Clone()`），因此回退不会撤销任何引擎状态。最外层放弃建设时，
    设施牌留在供应区、不消耗资源。
- **卡面接线**：`FacilitySupplyPanel.SpriteIndexOf(id)` 给出「卡面数组下标」——普通设施 100–140 → 0–40（按槽位 01–21、23–32、34–43）、核心指挥塔 200–203 → 41–44、延伸枢纽 300–302 → 45–47。
  `FacilitySupplyPanel.cardFaces` 与 `CityPanelView.cardFaces` 按这个顺序把 `card_facility.jpg` 切出的子 Sprite 拖进去即可显示卡面（不填则退回纯文字）。
